# Security Policy

## Supported Version

The public `index.html` file in this repository is the supported version.

## Reporting a Security Issue

Please report suspected security issues privately to the repository owner.
Do not open a public issue with exploit details.

## Security Notes

- This game is a static HTML, CSS, and JavaScript app.
- It does not send player data to a server.
- Scores are stored only in the browser's `localStorage`.
- No third-party scripts, analytics, ads, trackers, or network requests are used.
- The page includes a Content Security Policy to reduce browser attack surface.
