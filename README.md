# Math Adventure

Math Adventure is a browser-based maths game for children, with separate play
paths for ages 6-9 and ages 10-12.

## Publishing

Upload `index.html`, `LICENSE`, `SECURITY.md`, and this `README.md` to your
GitHub repository. If you enable GitHub Pages, `index.html` should be placed in
the repository root or in the configured Pages folder.

## Keeping Changes Under Your Control

For a public GitHub repository:

- Do not add collaborators unless you trust them to edit the code.
- Enable branch protection for `main`.
- Require pull requests before merging changes.
- Keep the repository license as `All rights reserved`.
- Review all pull requests yourself before accepting changes.

Important: because this is a public HTML game, browsers must receive the code in
order to run it. That means visitors can still view and copy the delivered HTML,
CSS, and JavaScript. The license and copyright notice protect your rights, but
they cannot make public client-side code technically uncopyable.
